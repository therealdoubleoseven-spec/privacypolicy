# Privacy Policy webpage

A responsive, accessible privacy policy page built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Before publishing

Replace the two supplied content placeholders in `client/src/pages/Home.tsx`:

- `[Insert App Name]`
- `[Insert Support Email Address]`

The policy text and effective date are based on the source material provided for this page. The page does not load third-party analytics or remote fonts.
